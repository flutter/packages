## 0.1.0

* Adds Media Foundation playback on Windows, with texture rendering, local and
  network sources, playback controls, buffering events and display sleep control.
* Supports custom HTTP headers, including authenticated range requests and safe redirects.
* Supports audio/video stream enumeration and selection, including restoring the
  original video stream and preserving display aspect ratios.
* Supports HLS/DASH bitrate selection and automatic adaptation through Windows
  AdaptiveMediaSource, with authenticated manifest, segment and HLS key requests.
