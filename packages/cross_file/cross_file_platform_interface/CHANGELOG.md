## 1.1.0

* Adds support to modify files and directories. See `PlatformXFile.openWrite`,
  `PlatformXFile.writeAsString`, `PlatformXFile.delete`, `PlatformXDirectory.createFile`,
  `PlatformXDirectory.createDirectory`, `PlatformXDirectory.delete`,
  `PlatformScopedStorageXFile.canWrite`, and `PlatformScopedStorageXDirectory.canWrite`.
* Updates documentation to more consistently use `resource` and `container`.
* Updates minimum supported SDK version to Flutter 3.41/Dart 3.11.

* Initial release.
